# 🏥 Hospital Emergency Room Data Analysis Dashboard

## 📌 About the Project

I created this Hospital Emergency Room Data Analysis Dashboard using Microsoft Power BI.

The dashboard is used to analyze hospital emergency room patient data and present the information through different visualizations and filters.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- Excel Dataset

## 🔄 What I Did

- Imported the hospital emergency room dataset into Power BI
- Cleaned and prepared the data using Power Query
- Created visualizations to analyze the patient data
- Used slicers and filters for interactive analysis
- Created a dashboard to present the analysis clearly

## 📊 Analysis Included

- Total Patients
- Patient Admission
- Department Referral
- Patient Gender
- Patient Age
- Average Waiting Time
- Patient Satisfaction
- Patient Visit Data
